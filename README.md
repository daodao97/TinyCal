## 这是什么

TinyCal 是一个 macOS **菜单栏日历**：不占 Dock 图标，点一下菜单栏就能弹出日历面板，随手看看今天农历初几、是不是法定节假日、要不要调休上班。目标很朴素——打开够快、信息够用、界面够干净。

## 主要功能

- **菜单栏自定义显示**：可自由组合显示“月日 / 星期 / 时分”，全部关闭时只显示一个日历图标；每分钟自动刷新。
- **月历面板**：点击菜单栏图标弹出，支持翻上月/下月、一键回到今天。
- **农历**：每个日期格可选显示农历日期，初一自动显示农历月份名。
- **法定节假日 / 调休提醒**：命中节假日显示节日名，命中调休上班日会用红色标出“班”字，数据来自第三方节假日 API 并做本地缓存，减少重复请求。
- **开机自启**：设置里一键开启，登录 macOS 后自动在菜单栏常驻。
- **首次使用引导**：第一次打开会自动弹出一次日历面板，帮助发现功能入口。

## 使用方式

1. 打开 TinyCal 后，菜单栏会出现一个日历相关的图标或文字。
2. 点击图标弹出日历面板，可以翻月、回到今天，点击某一天可查看/选中该日期。
3. 点击面板左上角设置按钮进入偏好设置，可分别配置：
   - **菜单栏**：是否显示月日 / 星期 / 时分；
   - **日历**：是否显示农历、是否显示假期标记；
   - **其他**：是否开机自启动。
4. 点击面板外部区域，面板会自动收起；也可以用 `⌘Q` 直接退出应用。

## 技术选型（简述）

TinyCal 使用 SwiftUI 编写日历面板与设置页面，用 AppKit（`NSStatusItem` + `NSPopover`）承载菜单栏交互，通过 Cron-Swift 驱动每分钟的菜单栏刷新，节假日数据来自 `timor.tech` 的公开 API 并以 JSON 文件形式缓存在沙盒 `Documents` 目录。更详细的模块划分、启动流程和已知问题，见 [ARCHITECTURE.md](./ARCHITECTURE.md)。
